## 4. E3 — локализация и число боксов (позитивы с ≥ 1 боксом)

Пары предсказание–GT (жадно по score, IoU > 0.1): IoU < 0.4 (ноль на всех порогах метрики) — 11 %, 0.4–0.75 (частичный зачёт) — 70 %, ≥ 0.75 (зачёт на всех порогах) — 20 %; медиана IoU 0.625.

| ситуация на позитиве | доля снимков | средний AP |
|---|---|---|
| предсказано больше боксов, чем в GT | 23 % | 0.273 |
| предсказано меньше боксов, чем в GT | 11 % | 0.247 |
| столько же боксов | 66 % | 0.561 |
| один бокс накрывает ≥ 2 GT-бокса («слияние») | 1.4 % | 0.135 |
| GT-бокс накрыт ≥ 2 боксами («дробление») | 6.1 % | – |

Контрфакты (среднее по сидам; прирост mAP на той же val; вся потеря на локализации 0.258): убрать боксы, не касающиеся ни одного GT (IoU ≤ 0.1; есть на 105 позитивах) — **+0.022**; убрать дубли (касаются GT, уже занятого боксом с большим score; 35 боксов) — +0.002; дать каждому сопоставленному боксу точные границы его GT — **+0.175**; всё вместе — +0.229. GT-боксов, которых не касается ни один бокс (IoU ≤ 0.1), на позитивах с боксами: 64. Размер: медиана √(площадь pred / GT) по парам с IoU > 0.4 ×1.011, предсказание больше GT в 52 % пар; по всем парам (IoU > 0.1) ×1.030 и 54 %; по парам с IoU 0.1–0.4 (11 % пар) ×1.686 и 75 %.

Лишний бокс на одноочаговых позитивах по терцилям размера: доля снимков с ≥ 2 боксами среди позитивов с одним GT-боксом и хотя бы одним боксом (среднее по сидам; в скобках — мин–макс по сидам): малые 53 % (49–57); средние 51 % (47–58); крупные 62 % (55–67).
